建议按这个顺序玩：
  1. 先拖动半径滑块（不要点单步）：看折线怎么被信赖域圆截断。 半径很小 → 走纯梯度方向（绿）；半径很大 → 直接走高斯牛顿步（蓝）；中间 → 落在橙色折线上。
  2. 再点「单步」几次：看每一步的 ρ（质量比）。ρ≈1 说明二次模型预测得准。
  3. 一直点下去：会遇到 ρ < 0 的步（红色拒绝）——高斯牛顿步跨过弯曲山谷冲到对面，代价反而上升，于是回滚、半径减半。 这就是动态半径的核心：步子迈大了就缩，走得好就放大。
  4. 看下方曲线：橙线是半径的演化，点的颜色是 ρ（绿=准／红=差）。
